# Project description

QoreLens is an open-source, static, testnet-only lab for the QoreX wallet on QoreChain's Diana testnet. A wallet can advertise post-quantum security features, but developers have no quick way to see which ones actually work. QoreLens runs the wallet through real tests, independently verifies the fixed-message ML-DSA-87 signature, and separately checks transaction outcomes against chain evidence. It checks the signature against the key registered on Diana, rejects five modified test inputs, and reads a deployed probe contract. A host-side RPC read records a successful transaction and the chain-reported hybrid verification event. Reports export as JSON and Markdown with an integrity digest and a build fingerprint. Tested with QoreX v0.4.3 on Diana. Only the message signature is independently verified by QoreLens. The transaction is chain-observed. The hybrid transaction signature bytes were not independently inspected.
